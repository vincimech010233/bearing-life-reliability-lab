# Research and scope — 2026-10-12

OBSERVED: [ISO 281:2007 public abstract](https://www.iso.org/standard/38102.html) associates basic rating life with 90% reliability and excludes wear/corrosion/electrical erosion. [NSK fatigue-life methodology](https://www.nsk.com/tools-resources/abc-bearings/dynamic-load-ratings-and-fatigue-life/) and [Schaeffler lubrication guide public indexed equations](https://www.schaeffler.com/remotemedien/media/_shared_media/08_media_library/01_publications/schaeffler_2/tpi/downloads_8/tpi_176_de_en.pdf) identify the basic power law, exponents, hours conversion and catalog-specific equivalent-load factors. We implement only the original algebraic basic-life calculation, not proprietary factors. Full paid ISO text was not obtained; no standard-conformance certification. Initial SKF/Schaeffler large catalog reads failed due web-reader size limits; retained as inconclusive, with accessible primary methodology used instead.

INFERRED justification: smaller pure-radial preliminary model with dimensional checks, analytic lognormal reference and explicit separation of parameter uncertainty from fatigue-population reliability.
